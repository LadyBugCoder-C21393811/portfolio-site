Projects

Below are some of the key projects I’ve worked on during my degree and industry experience. Each project demonstrates my ability to design, develop and deliver practical technology solutions using Java, SQL, databases, accessibility concepts and user-focused design.

Accessibility Navigation Mobile Application

Objective: Develop a navigation aid supporting people with disabilities by allowing users to assess and share accessibility information about locations.

  • Designed an application concept allowing users to search for or select locations on a map.
  • Created a colour-coded accessibility model (fully accessible, partially accessible, not accessible).
  • Added an optional review feature for users to provide detailed accessibility feedback.
  • Developed the concept of a shared accessibility information resource for future users.
  • Supported more informed decision-making for people assessing accessibility needs.

Technologies: MS Access, SQL, Java, Eclipse, NetBeans

Child Screen-Distance Mobile Application

Objective: Encourage children to avoid holding a device too close to their face using sensor-based detection and interactive responses.

  • Developed a concept using heat and motion sensors to detect when a face is too close to the screen.
  • Created an interactive response presenting age-appropriate questions when unsafe distance was detected.
  • Added parental controls allowing parents to adjust question difficulty.
  • Designed behaviour-based interaction encouraging children to recognise and change screen-distance habits.
  • Implemented a mechanism where correct answers allowed normal device use to continue.

Technologies: MS Access, SQL, Java, Eclipse, NetBeans

Dance School Database Management System

Objective: Build a functioning database supporting the day-to-day operations of a dance school.

  • Developed a database solution covering class scheduling, payment monitoring and student management.
  • Categorised students by age and dance experience level.
  • Included management of competition records.
  • Created a structured solution combining multiple areas of dance-school information into one system.
  • Demonstrated practical application of database design and SQL concepts in a real-world scenario.

Technologies: SQL, MS Access, Relational Database Design
